# site-labs-censo
Repositório para um protótipo de um site para a Procuradoria Educacional Institucional da UFRJ, que permita aos servidores inserirem e atualizarem informações dos laboratórios, a serem utilizadas para o Censo da Educação Superior..

# prototipo-labs
Protótipo com implementação fullstack

Para iniciar o projeto em react (com node.js):
- Baixar node.js

  npm install react-router-dom

Ir na pasta onde o projeto será criado e rodar

    npm create vite@latest

dar um nome pro projeto
selecionar o framework react
selecionar a “variant” Javascript (puro!)

Toda vez que quiser inicializar o site, rodar, dentro da pasta:

    npm run dev


Para poder usar o backend com flask

  pip install Flask
  pip install Flask-SQLAlchemy     
  pip install flask-cors
